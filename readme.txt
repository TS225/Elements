Elements
---------------------------------------

Code mostly written by Claude code. Small 'quiz' - type game to test players scientific knowledge about elements. Seems to accurate about correctness, but not thoroughly tested.
Software:
Binary distribution:
elements.prg
Source distribution:
elements2.asm

Machine target:
Commodore 64, PAL 50 hz, SID6581

ASM code syntax, compiled using ACME assembler:
ACME Cross-Assembler v. 0.97
multi-platform cross assembler for 6502/6510/65816 cpu
https://sourceforge.net/projects/acme-crossass/files/win32/

If not running in genuine hardware, VICE works:
https://vice-emu.sourceforge.io/

Install VICE and start elements.prg using VICEs 'File'- menu ->Smart attach .
